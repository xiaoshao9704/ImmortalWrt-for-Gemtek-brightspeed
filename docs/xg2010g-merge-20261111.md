## 保留与调整

1. 独立 1G/2G UBI profiles、显式内存、兼容别名、compat 2.0、0x20000 UBI
   起点及布局检查保留。不生成旧 vendor-layout 的同名 profile。U-Boot 仍可能
   改写 memory 节点；不修改引导程序。
2. 使用上游无 CPU DVFS/直接 PLL 策略，2G DTS 同步移除已删除节点引用。
   保留新 MAC 分配（CPU +4、lan4 +3）。不推测实际运行频率。
3. PPP 2.5.4 稳定版 r8 保留上游 514 TDB 修复，515 仅补齐 #638 hook 名及日志
   参数。firewall4 使用新上游源加原 nft 失败传播，避免重复旧 bridge patch。
4. 1G 使用 main 精简包集合，PBR 不打包；2G 旧包集合仍较大，本轮仅静态验证。
   保留语音镜像校验和、UPnP、msd_lite、ONU bridge fallback、无线 bridge
   过滤（对其他板型）及 2G offload 能力探测补丁。
5. 公共 feeds 保持 main 固定 SHA。移除不使用的 easytier、bandix、helloworld、
   pushbot 源及孤立 pushbot 翻译。provider 不再强制 helloworld，避免旧 checkout
   引入未固定的替代包。
6. 不导入 firmware_ota，不选择 luci-app-naoki66-ota、ac-agent、
   attendedsysupgrade、auc、owut。手动升级和共享基础库保留。
7. 自动同步仍禁用。新 CI 权限 contents:read，只上传 artifacts。main 原有
   手动/tag 发布工作流保留，但候选分支 push 不触发发布。

## 私有 feed 与发行二进制差异

只读拆检作者 20261111 XG2010G ITB（97,658,000 bytes）：revision 8e02d129、
Linux 6.18.60、xPON r69、pond r4、ONU UI r40。Release tag 却指向 a6dce40a。
实际 XG 镜像无 ac-agent，发布说明涵盖其他机型。

OTA 包 luci-app-naoki66-ota 1.0.0-r1 来自未公开 firmware_ota feed。它注册
admin/system/ota，带 luci.naoki66_ota RPC、naoki66-ota-fetch/mirror 助手，
默认 enabled/auto_check=1；Argon page_scripts.ut 加载 view.naoki66_ota.notice。
没有独立 init/cron。配置、manifest 和 rootfs 检查禁止这些构件与主题注入。

公共 PON HEAD 仍为 e19bde08ac3f3218a783f22165d9a5ded06046d2（r68），
ONU HEAD 为 3cb13560459f1d51136dac662baa1f399028b2b4（daemon r2）。作者的
pon-rx-stall-recovery-20261108.md 明说相关修复进入私有 feeds。

b36333bf0d 的 ONU 100 补丁及 7b81c1a42d 的 MSK 110 补丁可按序原样应用。
本分支合并为单一 patch 加到公共固定源，daemon 版本为 r4。PON 001/100
增量引用公共 r68 不存在的 RX-stall 状态机，不能直接套用，未从发行二进制
抽取或伪造缺失驱动。不能称本分支复现作者 r69 或解决了 PON 注册故障。
